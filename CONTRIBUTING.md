# Contributing to CipherShift

First off, thank you for considering contributing to CipherShift! It's people like you that make CipherShift such a great tool.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/maitanduc/ciphershift/issues) if it has already been reported. If not, open a new issue.

## Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`pytest`).
5. Ensure your code lints (`ruff check .` and `mypy .`).
6. Issue that pull request!
