# Security Policy

## Supported Versions

We currently only support the latest version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to Mai Tan Duc via [ducmai.network@gmail.com]. All security vulnerabilities will be promptly addressed.
